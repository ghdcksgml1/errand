# Errand 2.0.0

AI에 맡긴 일을 확인하는 위젯에 **작업 기록**과 **처음 시작하는 사용자를 위한 안내**를 더했습니다.

## 하루의 작업을 한눈에

- Codex와 Claude에 맡긴 일을 하루·주·월 단위로 모아 봅니다. 프로젝트별 작업 흐름, 커밋과 PR, 답변이 필요한 작업을 노선도에서 확인할 수 있습니다.
- 작업을 누르면 요청과 결과, 변경 파일을 함께 확인합니다. 다른 언어의 답변은 필요할 때 번역할 수 있습니다.
- 하루 요약을 수정하고 주간 보고서로 복사하거나, 한 주의 회고 카드를 이미지로 저장할 수 있습니다.

## 처음 시작할 때 직접 선택

- 앱 소개, 계정 확인, AI 설정, 첫 사용 안내로 이어지는 온보딩을 제공합니다.
- **자동 요약은 기본으로 꺼져 있습니다.** 설정을 완료하기 전에는 자동으로 요약하지 않으며, ‘나중에 설정’으로 건너뛸 수 있습니다.
- 기존 사용자의 AI 서비스·모델 설정도 불러옵니다. 요약을 켜면 요청·답변 일부와 커밋 메시지가 선택한 AI로 전송되고 해당 계정의 사용량에 반영됩니다. 번역은 직접 누를 때만 요청합니다.
- 한국어 문구를 다듬고, 오류 메시지는 선택한 언어로 표시합니다.

## 더 편한 위젯과 작업 관리

- 크게 보기, 간단히 보기, 캐릭터만 보기 중에서 공간에 맞는 크기를 고릅니다.
- 파일이나 이미지를 위젯에 놓아 개인 작업을 등록하고, 첨부 파일을 보관하거나 다시 열 수 있습니다.
- Claude 사용량을 앱 실행 시와 2분마다 갱신합니다. 전체 주간 한도와 모델별 한도를 구분해 표시합니다.
- 확인한 작업은 직접 체크할 때까지 유지합니다. Codex의 질문과 하위 작업도 구분해 보여줍니다.

## 보안과 배포

- 첨부 파일의 macOS 격리 정보를 보존하고, 작업방 인증정보를 서버별로 Keychain에 저장합니다.
- HTTP 응답 크기를 제한하며, 배포 파일에서 개인 빌드 경로가 남지 않도록 검사합니다.
- macOS 13 이상에서 사용할 수 있는 Apple Silicon·Intel 통합 앱입니다. 배포 파일은 Developer ID로 서명하고 Apple 공증을 받습니다.

앱의 업데이트 안내를 누르거나 `Errand-2.0.0.zip`을 내려받아 설치할 수 있습니다. 전체 변경 내역은 [CHANGELOG](../../CHANGELOG.md)를 참고하세요.
