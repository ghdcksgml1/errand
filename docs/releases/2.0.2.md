# Errand 2.0.2

파일이나 이미지로 작업을 등록할 때, AI가 제목과 메모를 추천하는 동안 두 칸을 잠그도록 바꿨습니다.

- 추천 중에 제목이나 메모를 입력해서 추천 결과가 버려지는 일이 없어집니다. 추천이 끝나면 바로 수정할 수 있습니다.
- 추천을 기다리지 않으려면 `직접 입력`을 눌러 추천을 멈추고 바로 적을 수 있습니다.

macOS 13 이상에서 사용할 수 있는 Apple Silicon·Intel 통합 앱입니다. Developer ID 서명과 Apple 공증을 완료했습니다.

앱의 업데이트 안내를 누르거나 [Errand-2.0.2.zip](https://github.com/ghdcksgml1/errand/releases/download/v2.0.2/Errand-2.0.2.zip)을 내려받아 설치할 수 있습니다. 전체 변경 내역은 [CHANGELOG](https://github.com/ghdcksgml1/errand/blob/v2.0.2/CHANGELOG.md)를 참고하세요.
