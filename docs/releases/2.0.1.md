# Errand 2.0.1

작업 기록에서 주·월을 연속으로 넘길 때 이전·다음 버튼을 같은 위치에서 누를 수 있도록 개선했습니다.

- 날짜 길이에 따라 움직이던 이전·다음 버튼을 날짜 왼쪽 아래에 고정했습니다.
- 버튼을 32px로 키우고 버튼 사이에 8px 간격을 두어 누르기 편하게 했습니다.

macOS 13 이상에서 사용할 수 있는 Apple Silicon·Intel 통합 앱입니다. Developer ID 서명과 Apple 공증을 완료했습니다.

앱의 업데이트 안내를 누르거나 [Errand-2.0.1.zip](https://github.com/ghdcksgml1/errand/releases/download/v2.0.1/Errand-2.0.1.zip)을 내려받아 설치할 수 있습니다. 전체 변경 내역은 [CHANGELOG](https://github.com/ghdcksgml1/errand/blob/v2.0.1/CHANGELOG.md)를 참고하세요.
