# 사용 설명서

Errand를 쓰는 데 필요한 내용입니다. 설치는 [README](../README.md)를 보세요.

## 위젯

데스크톱 오른쪽 아래에 사용량 위젯이 뜨고, 그 위에 작업 카드가 쌓입니다. 다른 앱을 쓰는 동안에도 떠 있고, 입력 중인 앱의 포커스를 가져가지 않습니다.

- **배터리**: Codex와 Claude의 남은 사용량과 다음 초기화 시각입니다. 한도가 여러 개면 가장 적게 남은 한도를 보여주고, 25% 이하면 빨갛게 바뀝니다. 조회에 실패하면 마지막 값을 회색으로 표시하고, 값을 받은 적이 없으면 비율을 표시하지 않습니다.
- **배터리 클릭**: 한도별 사용량과 초기화 시각을 말풍선으로 봅니다.
- **새로고침 아이콘**: 사용량을 바로 다시 읽습니다. 자동으로는 2분마다 읽습니다.
- **프로필**: 내 캐릭터와 닉네임입니다. 캐릭터를 누르면 캐릭터를 꾸미고 닉네임을 바꿀 수 있습니다. 닉네임은 Return을 누르거나 창을 닫으면 저장되고, 20자까지입니다. 직접 정하지 않았거나 칸을 비우면 Claude에 설정한 이름, Codex 계정 이름, Mac 사용자 이름 순으로 정해집니다.
- **작업방 버튼**: 닉네임 오른쪽의 `작업방`을 누르면 방 목록이 열립니다. 방에 들어가 있으면 탭 줄 끝의 `+`가 같은 일을 합니다.
- **드래그**: 위젯과 카드를 함께 옮깁니다. 위치는 다음 실행에도 유지됩니다.
- **메뉴 막대**: 앱 열기, 사용량 창, 작업방, 위젯 크기, 위젯 숨기기와 위치 초기화가 있습니다. 쓰지 않는 서비스는 `Codex 표시`·`Claude 표시`를 꺼서 숨길 수 있고, 숨기면 사용량도 읽지 않습니다.

### 위젯 크기

화면이 작은 노트북에서는 위젯을 줄일 수 있습니다. 메뉴 막대나 위젯을 우클릭해서 `크게 보기`, `간단히 보기`, `캐릭터만` 가운데 하나를 고르고, 고른 크기는 다음 실행에도 유지됩니다. 크기를 바꿔도 위젯은 화면에서 가까운 쪽 모서리를 지키며 그 자리에서 줄고 늘어납니다.

- **간단히 보기**: 답변 필요·새 결과·진행 중 개수와 서비스별 작은 배터리를 한 줄로 보여 줍니다. 나를 부르는 일, 곧 `답변 필요`, `새 결과`, `응답 없음`인 일만 그 위에 한 줄 카드로 올라오고, 열어 보면 내려갑니다. 개수를 누르면 진행 중이거나 확인한 일까지 모두 펼치고, 배터리를 누르면 사용량 말풍선이 열립니다. 줄에 마우스를 올리면 요청과 결과가 보이고, 동그라미로 카드처럼 정리합니다.
- **캐릭터만**: 내 캐릭터 하나만 둡니다. 나를 부르는 일이 있으면 숫자 배지가 붙고(질문이 있으면 주황, 아니면 파랑), 일이 진행되는 동안 테두리에 청록 호가 돌고, 사용량이 25% 이하인 서비스가 있으면 빨간 배터리가 붙습니다. 마우스를 올리면 간단히 보기가 위에 나타나고, 캐릭터를 누르면 프로필 꾸미기가 열립니다.
- 두 크기에서는 프로필과 작업방 탭이 보이지 않습니다. 작업방은 메뉴 막대의 `작업방`으로 열고, 들어가 있는 방에는 그대로 개수를 전합니다.

화면 문구는 맥의 언어 설정에 따라 한국어나 영어로 나옵니다. 언어를 바꾸려면 시스템 설정의 `일반` > `언어 및 지역` > `응용 프로그램`에 Errand를 추가합니다.

## 작업 카드

Codex와 Claude에 시킨 세션이 카드로 쌓입니다. 무엇을 시켰고 어떻게 끝났는지가 남아서, 맡겨둔 일을 놓치지 않게 합니다.

- 왼쪽 동그라미를 체크해야만 사라집니다. 5초 안에는 `되돌리기`로 취소할 수 있고, 정리한 세션에 새로 요청하면 다시 나타납니다.
- 상태는 색으로 구분합니다: `새 결과`(파랑), `진행 중`(청록), `답변 필요`(주황), `확인함`(회색), `응답 없음`(빨강, 20분 넘게 기록이 없음), `중단됨`(회색).
- Codex가 입력을 요청하거나 Claude가 질문·계획 승인을 기다리면 카드가 `답변 필요`로 바뀌고 질문 내용이 나옵니다. 맨 위 개수에도 따로 세고, 답을 기다리는 동안에는 `응답 없음`이 되지 않습니다. Codex의 비동기 질문은 작업이 계속되는 동안에도 답변할 수 있습니다. 명령 실행 허락을 묻는 창은 현재 기록 읽기 방식으로 추적하지 않아 `진행 중`으로 보일 수 있습니다.
- 카드를 누르면 그 대화가 Codex나 Claude에서 바로 열립니다.
- Codex의 서브 에이전트와 Claude의 하위 작업은 부모 카드 안에 줄로 들어갑니다. 줄을 누르면 그 세션이 열리고, 줄의 동그라미로 그 작업만 정리합니다. 위 카드를 체크하면 `확인함`인 줄은 함께 사라지고, 나머지 줄은 따로 카드가 됩니다. Codex의 내부 승인 검토용 에이전트는 표시하지 않습니다.
- Claude에서 마지막으로 연 세션은 Claude가 맨 앞에 있을 때 답이 끝난 뒤 키보드나 마우스를 쓰면 `확인함`으로 바뀝니다. 지금 어느 탭을 보는지는 알 수 없어서, Claude의 Chat 탭을 보고 있어도 바뀔 수 있습니다.
- 맨 위의 `내가 시킨 작업` 줄을 누르면 카드를 접고 펼칩니다. 접어도 상태별 개수는 보입니다.

세션은 각 앱이 이 Mac에 남기는 기록을 읽기만 해서 찾습니다. 원본 파일은 바꾸지 않습니다. Codex는 `~/.codex`, Claude는 데스크톱 앱의 Code 세션 기록과 `~/.claude/projects`를 읽습니다. 터미널에서 직접 실행한 Claude Code 세션은 카드로 나오지 않습니다.

## Claude 사용량

Errand는 Claude Code의 로그인을 읽지 않고, Claude Code가 직접 알려주는 값을 씁니다. 값은 두 곳에서 받습니다.

- **`새로고침`을 누를 때**: 데스크톱 앱에 든 Claude Code로 `/usage`를 실행해 읽습니다. 모델별 주간 한도까지 받습니다. 모델을 부르지 않아서 사용량이 들지 않고, 세션 기록도 남지 않습니다. 사람이 누를 때만 실행하고, 자동 갱신으로는 실행하지 않습니다.
- **터미널에서 Claude Code를 쓰는 동안**: `python3 scripts/connect_claude.py`를 한 번 실행하면 Claude Code의 [status line](https://code.claude.com/docs/en/statusline)으로 `5시간`과 `주간` 한도를 자동으로 받습니다. `~/.claude/settings.json`의 `statusLine`만 추가하고, 이미 쓰는 status line이 있으면 바꾸지 않습니다. 해제하려면 그 항목을 지웁니다.

데스크톱 앱의 Code 세션은 status line을 실행하지 않아서, 데스크톱 앱만 쓴다면 `새로고침`을 눌러야 값이 바뀝니다. 값은 Pro·Max·Ultra 구독에서만 옵니다. Claude 카드에는 조회 시각 대신 `Claude Code 기준` 시각이 붙고, 초기화 시각이 지난 한도는 다시 알려줄 때까지 표시하지 않습니다.

## 작업방

같은 방 사람들이 몇 개의 일을 돌리고 있는지만 보면서 같이 일하는 기분을 내는 기능입니다. 닉네임 오른쪽의 `작업방` 버튼이나 메뉴 막대의 `작업방`에서 방 목록을 엽니다. 들어간 방은 프로필 아래에 탭으로 붙고, 다음 실행에도 기억합니다. 방에 들어가 있으면 버튼 대신 탭 줄 끝의 `+`로 목록을 엽니다.

방은 3개까지 들어갈 수 있고, 다른 방을 나가면 새 방에 들어갈 수 있습니다. 탭이 한 줄에 다 들어가지 않으면 탭 줄 위에서 좌우로 스크롤합니다.

- **공개 방**: 누구나 들어옵니다. 이름은 보내지 않고, 방이 붙여 준 별명과 캐릭터로 보입니다.
- **비공개 방**: 초대받은 사람만 들어옵니다. 닉네임과 캐릭터로 보입니다.
- 캐릭터는 어느 방에서나 같아서, 두 방에서 같은 캐릭터를 보면 같은 사람이라고 짐작할 수 있습니다.

**비공개 방 만들기와 초대.** 방 목록 위의 `방 만들기`로 이름(30자까지)과 한 줄 소개를 정하면 비공개 방이 생기고, 만든 사람이 방장이 되어 바로 들어갑니다. 방은 5개까지 만들 수 있습니다.

- **초대 링크**: 방장의 방 카드에 있는 `초대`를 누르면 링크가 나옵니다. 링크는 7일 동안 10명까지 쓸 수 있고, `새 링크 만들기`를 누르면 이전 링크는 더 쓸 수 없습니다. 링크를 지워도 이미 들어온 사람은 그대로입니다.
- **링크로 들어오기**: 받은 사람이 링크를 누르면 브라우저가 한 번 열린 뒤 Errand가 그 방을 보여 줍니다. 들어가기 전에는 방 이름과 소개, 인원만 보이고, 누가 작업 중인지는 들어간 뒤에 보입니다. 링크를 여는 것만으로는 들어가지 않고, `들어가기`를 눌러야 들어갑니다. 코드는 링크의 `#` 뒤에 있어서 서버로 전송되지 않습니다.
- **인원**: 비공개 방에는 방장을 포함해 20명까지 초대받을 수 있습니다.
- **코드로 들어오기**: 링크를 못 여는 경우 방 목록의 `초대 코드 입력`에 `K7QF-M2XA-9P` 같은 코드를 붙여넣습니다. 대소문자와 구분 기호는 상관없습니다.
- **빠지기와 내보내기**: 들어가 있지 않은 비공개 방의 `빠지기`를 누르면 목록에서 사라지고, 다시 들어오려면 새 초대가 필요합니다. 방장은 위젯의 멤버 줄을 우클릭하거나, 초대 화면의 `멤버 관리`에서 지금 방에 없는 사람까지 내보낼 수 있고, 내보낸 사람은 새 링크로만 다시 들어올 수 있습니다. 멤버 관리에는 지금 없는 멤버도 마지막으로 들어왔을 때의 닉네임으로 보이도록, 서버가 비공개 방 멤버의 닉네임과 캐릭터, 마지막으로 들어온 때를 방에 남겨 둡니다. 방에서 빠지거나 내보내지거나 방이 없어지면 함께 지워집니다. 초대 화면 아래의 `방 없애기`로 방을 없앨 수 있습니다. 모두 한 번 묻고 진행합니다.
- **방장의 Mac**: 로그인 없이 이 Mac의 설치 ID로 방장을 알아봅니다. 방장의 Mac에서 Errand를 90일 넘게 쓰지 않거나 다시 설치해 설치 ID가 바뀌면, 방은 모든 멤버에게서 사라집니다.

**무슨 작업인지는 공유하지 않습니다.** 서버(`errand-backend.vercel.app`)에 보내는 것은 새 결과·진행 중·확인함의 개수, 캐릭터, 비공개 방에서의 닉네임, 이 설치의 ID, Errand 버전, 화면 언어뿐입니다. 제목, 요청, 결과, 폴더는 담을 자리가 없습니다. 작업방을 쓰지 않으면 아무것도 보내지 않습니다.

## 업데이트

앱을 켤 때와 하루에 한 번 GitHub에 최신 버전을 묻습니다. 보내는 것은 Errand 버전뿐입니다.

새 버전이 있으면 위젯의 프로필 옆과 메뉴 막대 메뉴 맨 위에 표시됩니다. 저절로 설치되지 않고, 누를 때만 내려받습니다. 받은 앱은 Errand의 Developer ID 서명과 Apple 공증을 확인한 뒤에만 교체하고, 하나라도 어긋나면 지금 앱을 그대로 둡니다.

## 자동 실행

`python3 scripts/install.py --update --autostart`로 설치하면 맥에 로그인할 때 Errand가 열립니다. 해제하려면 다음을 실행합니다.

```sh
launchctl bootout "gui/$(id -u)/com.errand.login"
rm "$HOME/Library/LaunchAgents/com.errand.login.plist"
```

## 저장되는 내용

모두 이 Mac의 `~/Library/Application Support/Errand`에 있습니다. 요청이나 응답 내용, 로그인 토큰은 저장하지 않습니다.

| 파일 | 내용 |
| --- | --- |
| `session-tray.plist` | 세션별 완료·확인 시각 |
| `pet-history.plist` | 한도별 초기화 시각 |
| `claude-usage.plist` | Claude 한도별 남은 비율과 초기화 시각 |
| `rooms.plist` | 들어간 작업방의 ID와 비공개 여부 |

캐릭터와 이 설치의 ID는 앱 설정(`com.errand.app`)에 있습니다. 이 ID는 처음 실행할 때 무작위로 만든 값이고, 작업방 서버에만 보냅니다.
